1 채널별 API 인증 관리

⚠️ 원본 문서 누락 항목

원본 문서는 "자동 게시 — API"라고만 명시. 각 채널별 인증 방식·토큰 관리·갱신 주기가 없어 개발 착수 불가.

인스타그램 (Meta Graph API)

항목내용
인증 방식OAuth 2.0 — Meta for Developers 앱 생성 후 Long-lived Access Token 발급
토큰 유효기간Short-lived 1시간 → Long-lived 60일 → 만료 전 자동 갱신
갱신 방법GET /refresh_access_token — 만료 7일 전 스케줄러 자동 실행
필요 권한instagram_basic, instagram_content_publish, pages_read_engagement
게시 APIContainer 생성 → POST /{ig-user-id}/media → 게시 POST /{ig-user-id}/media_publish
일일 제한계정당 50회/일 (게시 기준)

네이버 블로그

항목내용
인증 방식네이버 개발자 센터 OAuth 2.0 — Client ID/Secret 발급
Access Token유효기간 1시간, Refresh Token으로 재발급 (최대 6개월)
게시 APIPOST https://openapi.naver.com/blog/writePost.json
필요 권한블로그 글쓰기 스코프: blog
HTML 본문SEO 최적화 HTML 생성 — <h1> 태그 키워드 포함 필수

네이버 밴드

항목내용

필요 조건동네할인 공식 밴드 사전 개설 필요, 밴드 Key 등록

카카오톡 채널

항목내용
인증 방식카카오 비즈니스 채널 + Admin Key
메시지 유형카드형 메시지 (카카오 메시지 템플릿 사전 심사 필요 — 약 3~7일)
발송 APIPOST https://kapi.kakao.com/v1/api/talk/channels/message
제한하루 1,000건 무료, 초과 시 유료 전환
주의마케팅 메시지 — 수신 동의한 사용자에게만 발송 가능
🔐 API 키 보안 관리
  • 모든 API 키/Secret은 Supabase Vault 또는 환경변수(.env)로 관리 — 코드에 하드코딩 금지
  • 토큰 만료 7일 전 관리자 이메일 알림 발송
  • 토큰 갱신 실패 시 해당 채널 자동 비활성화 + 관리자 긴급 알림

3 이미지 생성 및 처리 정책

⚠️ 원본 문서 누락 항목

원본 문서는 "이미지 최적화 — 채널 비율 자동 변환"만 언급. 이미지 소스 정의 및 fallback 처리 없음.

8 금칙어 및 AI 프롬프트 가이드

⚠️ 원본 문서 누락 항목

원본 문서 "금칙어 필터" 언급만 있고 실제 목록 없음. 법적 리스크 방지를 위해 필수.

절대 금칙어 (자동 차단)

과장·허위 광고
  • 국내 최고, 세계 최초, 업계 1위
  • 100% 보장, 완전 무료, 공짜
  • 혁명적, 기적의, 특효
  • 의사 추천, 병원 인증
법적 리스크
  • 다이어트 효과, 체중 감량 보장
  • 피부 개선 보장, 탈모 치료
  • 경쟁사 브랜드명 (스타벅스, 맥도날드 등)
  • 의약품 효능 주장
